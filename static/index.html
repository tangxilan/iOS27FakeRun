如何模拟校园跑（无需地图画好跑道）
① 搜学校飞到操场：在右侧卫星图上方输入学校或校区名（例如 西安建筑科技大学，或直接输 纬度,经度），点击结果即可飞过去，点 × 关闭 可收起列表。
② 3 种方式画跑道：
  • 400m 标准跑道生成器（最推荐）：点操场正中心，拖动直道/半径/旋转角度滑块直接对齐卫星图白线；
  • 卫星图点击打点：自己沿操场点出一圈，支持拖拽微调和弯道平滑；
  • 手动改经纬度 / 导入导出：可在表格里逐行填写精确经纬度，也兼容原版 iOSFakeRun JSON 与 GPX 文件。
③ 调好配速开跑：设置速度（如 3.2 m/s）和圈数后点 开始模拟校园跑，跑步过程中也能随时调速。跑完后软件会保持终点定位，先在手机 App 里点结束并提交成绩！
如何精确锁定打卡位置
① 选点或输坐标：切到左侧 📍 定点定位打卡，直接点击卫星图上的教学楼/实验楼，或者手动输入纬度、经度（注意选对坐标系：高德/腾讯为 GCJ-02，百度为 BD-09，GPS 原生为 WGS-84）。
② 锁定防回弹：点击 📌 锁定此定位（开始打卡），软件会持续维持虚拟位置，防止 iPhone 自动跳回真实 GPS。
③ 方向盘微调与收藏：如果打卡范围差几十米，直接点东南西北按钮（5m / 15m / 50m）微调；常用教室可点 收藏当前点 保存，下次一点直达。
使用完毕务必恢复真实 GPS + 进阶无线玩法
⚠️ 重要提醒：每次跑完步或打完卡，务必点击顶部红色按钮 一键恢复真实定位（或重启 iPhone），否则手机导航、外卖定位会一直停留在模拟位置。
📶 Wi-Fi 无线连接 iPhone：插 USB 时点顶部 无线配对，成功后下次电脑和 iPhone 连同一 Wi-Fi，不插线也能直接连接定位。
📱 安卓手机遥控苹果手机：双击文件夹里的 局域网远程启动.bat，点顶部 日志 / 手机遥控 查看局域网网址，用安卓手机浏览器打开就能远程操作。
