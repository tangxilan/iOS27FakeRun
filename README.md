# iOS27FakeRun

一个**免越狱、免费开源**的 iOS 虚拟定位桌面软件，原生支持 **iOS 17 ~ iOS 27+**（同时兼容 iOS 16 及以下旧版本）。

本项目参考 [Mythologyli/iOSFakeRun](https://github.com/Mythologyli/iOSFakeRun) 的设计思路重写，针对**高校模拟校园跑**（地图里往往没画校内操场跑道，需要完全自主设计轨迹或手写经纬度）以及**教学楼/实习定点定位打卡**场景量身打造，提供中文卫星图图形化界面，**不需要懂代码、不需要管理员权限**，解压装好依赖即可使用，也支持在同局域网下用**安卓手机浏览器遥控电脑上的苹果手机**。

---

## 功能亮点

- **真正兼容 iOS 17 ~ iOS 27+（免越狱）**
  - 基于 `pymobiledevice3` 的纯用户态 `UserspaceRsdTunnel` 与 DVT `LocationSimulation` 通道，在 Windows 下无需管理员权限即可在约 1 秒内连上 iPhone。
  - 支持 iOS 17–26 的个性化开发者镜像及 iOS 26.4+/27 的 Cryptex1 开发者镜像按需自动挂载，同时兼容 iOS 16 及以下版本。
- **模拟校园跑（不依赖地图软件道路导航）**
  - **高德卫星图 / Esri 全球卫星图直接手绘**：想怎么跑就怎么点，支持拖拽微调节点、反转顺逆时针方向、Catmull-Rom 弯道平滑。
  - **标准 400m 操场跑道一键生成器**：就算地图上完全没画校内跑道，在卫星图操场中央点一下，拖动“直道长度 / 弯道半径 / 旋转角度”滑块就能严丝合缝贴合真实操场跑道。
  - **纯手动经纬度表格 & 批量导入导出**：可直接在表格中逐行手写、修改任意节点的精确纬度/经度；兼容原版 `iOSFakeRun` 的 BD-09 JSON、`lat,lng` 纯文本与 GPX 轨迹文件；常用路线可本地一键收藏。
  - **逼真跑步策略**：支持按圈数或按目标总里程跑步，速度（`m/s`）与配速（`分'秒"/km`）双向联动且**支持跑步途中实时调速**；内置自然速度波动与多圈轨迹微漂移，避免每圈轨迹完全重合；跑完后自动保持终点定位等待你在手机提交记录。
- **定点定位打卡**
  - 在卫星图点选或手动输入目标经纬度，一键锁定位置并定时心跳保活，防止 iOS 真实 GPS 回弹。
  - 自带 **东南西北方向微调盘**（步长可选 `5m / 15m / 50m`），签到范围稍有偏差一点即移；支持常用打卡点（如教学楼、实验楼、体育馆）收藏与一键切换。
  - 窗口顶部常驻醒目红色按钮 **一键恢复真实定位**，用完随时秒回真实 GPS。
- **坐标系高精度无偏移**
  - 内置 `WGS-84`、`GCJ-02`（高德/腾讯）、`BD-09`（百度/原版 `iOSFakeRun`）高精度互转（迭代反解误差 `< 0.01m`），彻底解决国内地图“图上点在这里、手机定位偏到 500 米外”的问题。
- **Windows 原生窗口 + 安卓手机局域网遥控 + Wi-Fi 无线连接**
  - Windows 下采用 Edge WebView2 独立桌面窗口打开，无黑框控制台；
  - 同一 Wi-Fi 下支持安卓手机浏览器直接控制；USB 引导一次 **无线配对** 后，下次不插数据线也能通过 Wi-Fi 连接 iPhone。

## 零基础安装指南（给同学看，两种方式任选）

> **适用电脑**：Windows 10 / Windows 11（64 位）  
> **适用手机**：任意 iPhone（iOS 14 ~ iOS 27+ 均可，无需越狱）

### 方式一：直接下载 EXE 压缩包（最推荐，免装 Python！）
1. 打开本项目的 [Releases 发布页面](https://github.com/tangxilan/iOS27FakeRun/releases)；
2. 下载最新版本的 **`iOS27FakeRun-v*-win64.zip`** 并完整解压到一个文件夹；
3. 直接双击 **`iOS27FakeRun.exe`** 启动软件（需要用安卓手机遥控时双击同目录的 **`局域网远程启动.bat`**）；
4. 首次打开会自动弹出 **环境检测与新手引导**，如果系统缺少 Apple 手机驱动，直接点击弹窗内的按钮即可跳转微软商店安装 **Apple 设备** 或下载 **iTunes**。

---

### 方式二：下载源码自行运行

#### 第 1 步：下载本项目
1. 打开本仓库主页，点击右上角绿色按钮 **`<> Code`** -> **`Download ZIP`**。
2. 将压缩包解压到一个**纯英文或不含特殊符号的文件夹**（例如桌面或 D 盘的 `iOS27FakeRun` 文件夹）。

#### 第 2 步：安装 Python（如果电脑还没装）
1. 下载 **Python 3.12**（64 位 Windows 安装包）：
   - 官网：https://www.python.org/downloads/windows/
   - 国内高速镜像（推荐）：https://mirrors.huaweicloud.com/python/3.12.10/python-3.12.10-amd64.exe
2. 运行安装包时，**务必勾选最底部的 `Add python.exe to PATH`**，然后点击 `Install Now` 完成安装。

#### 第 3 步：确保电脑有 Apple 驱动
- 请在 Windows **Microsoft Store（微软应用商店）** 搜索并安装 **Apple Devices（Apple 设备）** 或 **iTunes**（官网桌面版也可）。
- 安装后用数据线插上 iPhone，在手机弹窗里输入锁屏密码并点击 **信任此电脑**。

#### 第 4 步：一键安装软件依赖
- 打开解压后的 `iOS27FakeRun` 文件夹，双击运行：
  ```text
  安装依赖.bat
  ```
- 脚本会自动创建 `.venv` 虚拟环境并从国内镜像安装所需组件。看到终端提示 `[OK] Setup complete!` 后关闭窗口即可。

---

### 开启 iPhone 的“开发者模式”（每台手机只需开一次）
1. 在 iPhone 上打开：**设置 -> 隐私与安全性 -> 开发者模式**。
2. 打开开关，按系统提示**重启手机**，开机后输入密码确认开启。
> **提示**：如果你的 iPhone 里找不到“开发者模式”这一行，先插上数据线并信任电脑，然后打开本软件点击顶部按钮 **开发者开关**，手机设置里就会立刻显示出“开发者模式”选项。

## 详细使用教程

### 一、启动与连接 iPhone
1. 双击文件夹里的 **`启动软件.bat`**（也可以直接双击 `desktop_app.pyw`），等待 1~2 秒弹出桌面窗口。
2. 确保 iPhone 已通过数据线连接电脑且屏幕已解锁，点击顶部 **刷新设备**，下拉框会出现 `[USB] 你的iPhone (iOS xx.x)`。
3. 点击 **连接设备**，状态栏变成绿色 `已连接 ...` 即表示就绪（iOS 27 通常 1 秒左右连接成功；首次连接部分旧版系统可能需要自动下载约 17MB 的开发者镜像，耐心等待提示完成即可）。

### 二、功能 1：模拟校园跑
1. 切换到左侧 **🏃 模拟校园跑** 标签页。
2. **定位到你的学校操场**：在右侧地图顶部搜索框输入学校名称，或直接输入 `纬度,经度`（例如 `39.9928, 116.3102`）点 **跳转** 飞往操场。
3. **设计操场跑道（3 种方式任选）**：
   - **方式 A · 400m 标准跑道生成器（最省事）**：展开 **标准 400m 操场跑道一键生成器**，点 **在地图点选操场中心** 后点一下操场正中间，再拖动“旋转角度 / 直道长度 / 弯道半径”滑块，直到蓝色跑道圈和卫星图跑道白线完全重合。
   - **方式 B · 卫星图手绘打点**：保持 **点击打点** 状态，沿着操场或校园路依次点击关键点（可切到 **拖拽微调** 拖动节点，右键节点可删除），觉得拐弯太生硬可点 **弯道平滑**。
   - **方式 C · 纯手动改经纬度 / 导入原版数据**：切到 **手动改经纬度** 可逐点手改坐标；切到 **批量导入/导出** 可直接粘贴坐标文本、GPX 文件或原版 `iOSFakeRun` 网页拾取器生成的 JSON（记得选对导入坐标系）。
4. **设置参数并开跑**：
   - 设定跑步速度（例如 `3.2 m/s`，右侧自动换算为 `5'13"/km` 配速，**跑步途中也可以直接修改速度**）。
   - 选择 **按圈数跑步**（如 5 圈）或 **按目标总里程**（如 2000 米）。
   - 建议保留默认的速度波动（`±8%`）和轨迹微漂移（`0.8m`），让多圈轨迹更自然。
   - 点击 **▶ 开始模拟校园跑**，随后打开 iPhone 上的校园跑 App 开始运动记录即可。
5. **结束与还原**：跑到目标后软件会自动停在终点保持定位，请先在手机 App 里点**结束并提交/上传跑步记录**，然后再点击本软件顶部红色按钮 **一键恢复真实定位**！

### 三、功能 2：定点定位打卡
1. 切换到左侧 **📍 定点定位打卡** 标签页。
2. 在右侧卫星图上点击你要签到的位置，或者在输入框手动填写**纬度**和**经度**（注意选对输入坐标系：`WGS-84` / `GCJ-02` / `BD-09`）。
3. 点击 **📌 锁定此定位（开始打卡）**，此时 iPhone 的系统定位会被牢牢锁在该位置。
4. 如果打卡 App 提示距离差一点，直接用下方的 **东南西北微调方向盘**（每次移动 5m / 15m / 50m）实时微调；常用教室或公司打卡点可以点 **收藏当前点** 保存起来下次一键定位。
5. 打卡成功后，记得点击 **解除并恢复真实GPS** 或顶部红色按钮 **一键恢复真实定位**。

### 四、进阶玩法：无线连接 & 安卓手机遥控
- **无线 Wi-Fi 连接 iPhone（免插线）**：在 USB 已连接电脑的状态下，点击软件顶部 **无线配对**，成功后下次只要 iPhone 和电脑在同一个 Wi-Fi 下，刷新设备即可在下拉框选择 `[Wi-Fi] 已配对设备` 进行无线模拟。
- **用安卓手机遥控操作**：确保 iPhone 已连上电脑（USB 或 Wi-Fi 均可），双击 **`局域网远程启动.bat`** 打开软件，点击右上角 **日志 / 手机遥控** 查看局域网地址（如 `http://192.168.x.x:8765`），安卓手机连同一 Wi-Fi 后用浏览器打开该地址即可直接画线、开跑、微调打卡点。
  > 若手机打不开，请在 Windows 防火墙弹窗点击允许 Python 访问专用/公用网络，或放行端口 `8765`。

## 常见问题排查 (FAQ)

1. **双击 `安装依赖.bat` 提示找不到 Python？**
   - 重新运行 Python 3.12 安装包并确保勾选了 **`Add python.exe to PATH`**，安装完毕后重新双击 `安装依赖.bat`。
2. **点“刷新设备”看不到 iPhone？**
   - 检查是否已安装 **Apple Devices** 或 **iTunes**；
   - 换一根支持数据传输的线（部分充电线不能传数据），解锁手机并在弹窗中点 **信任此电脑**；
   - 确认系统服务 `Apple Mobile Device Service` 正在运行。
3. **打开软件点“连接设备”提示未开启开发者模式，但手机设置里找不到？**
   - 先插线并点击软件顶部的 **开发者开关** 按钮，再去手机 **设置 -> 隐私与安全性** 最下方查看即可出现“开发者模式”。
4. **为什么我在高德地图上选的点，放到百度/GPS 上差了几百米？**
   - 中国大陆地图坐标系不同（高德/腾讯为 `GCJ-02`，百度为 `BD-09`，iPhone 原生定位为 `WGS-84`）。在本软件地图上直接点选时会自动转换无需操心；如果是**手动粘贴/输入经纬度**，请务必把下拉框选成该坐标原本所属的坐标系。
5. **双击 `启动软件.bat` 没反应？**
   - 双击 **`调试模式启动.bat`**，黑框里会直接显示报错原因（常见原因是未运行 `安装依赖.bat` 导致缺少 `.venv`），也可查看 `data/desktop.log`。
6. **忘记点恢复真实定位就拔了线，手机一直停在假位置怎么办？**
   - 重新插回电脑点一次 **一键恢复真实定位**，或者直接**重启 iPhone** 即可恢复真实 GPS。

## 项目目录说明

```text
iOS27FakeRun/
├── backend/                # FastAPI 后端、坐标转换、轨迹生成、模拟引擎、pymobiledevice3 设备控制
├── static/                 # 前端网页界面与本地化 Leaflet 1.9.4 地图库
├── tests/                  # 自动化单元测试与 API 测试
├── desktop_app.pyw         # Windows 原生图形窗口启动入口 (Edge WebView2)
├── run_server.py           # 纯后端/命令行 Web 服务启动入口
├── 安装依赖.bat             # 首次使用一键创建 .venv 并安装依赖
├── 启动软件.bat             # 本机桌面图形界面一键启动
├── 局域网远程启动.bat        # 桌面界面 + 安卓手机局域网遥控模式启动
├── 调试模式启动.bat          # 带终端输出的排障启动脚本
├── requirements.txt        # Python 依赖清单
└── LICENSE                 # GNU GPL v3.0 开源协议
```

*(注：运行后生成的个人路线收藏、打卡点、运行日志均保存在 `data/` 目录中，`.gitignore` 已将其自动忽略。)*
